# Telegram Network Diagnostics

🔍 CLI инструменты для диагностики и мониторинга сетевого соединения с Telegram Bot API

## Возможности

- ⚡ **Быстрая проверка** - проверка соединения за несколько секунд
- 📊 **Непрерывный мониторинг** - отслеживание качества соединения в реальном времени
- 🔬 **Полная диагностика** - комплексная проверка DNS, TCP, задержки, загрузки файлов

## Установка

### Из исходников

```bash
git clone https://github.com/asbtlt/telegram-network-diagnostics.git
cd telegram-network-diagnostics
pip install -e .
```

### Через pip (после публикации)

```bash
pip install telegram-network-diagnostics
```

## Использование

### Быстрая проверка

Выполняет 5 тестовых запросов к API и показывает статистику:

```bash
# С указанием токена
telegram-diag check YOUR_BOT_TOKEN

# Или с config.py (см. ниже)
telegram-diag check
```

**Пример вывода:**

```
🔍 Быстрая проверка Telegram API...

✅ Попытка 1/5: 234.12ms
✅ Попытка 2/5: 245.67ms
✅ Попытка 3/5: 256.78ms
✅ Попытка 4/5: 243.45ms
✅ Попытка 5/5: 239.23ms

==================================================
📊 Статистика:
   Успешных запросов: 5/5
   Средняя задержка: 243.85ms
   Мин/Макс: 234.12ms / 256.78ms

✅ Состояние: ОТЛИЧНОЕ
==================================================
```

### Непрерывный мониторинг

Запускает непрерывный мониторинг с указанным интервалом:

```bash
# С интервалом по умолчанию (5 секунд)
telegram-diag monitor YOUR_BOT_TOKEN

# Или с config.py
telegram-diag monitor

# С кастомным интервалом (10 секунд)
telegram-diag monitor --interval 10

# С увеличенной историей (100 проверок)
telegram-diag monitor --history 100
```

**Возможности мониторинга:**

- Отображение статуса каждой проверки с эмодзи-индикаторами
- Статистика каждые 20 проверок
- Гистограмма распределения задержек
- Автосохранение результатов при остановке (Ctrl+C)

**Индикаторы:**

- 🟢 Отлично (<300ms)
- 🟡 Хорошо (300-500ms)
- 🟠 Удовлетворительно (500-1000ms)
- 🔴 Плохо (>1000ms)
- ❌ Ошибка

### Полная диагностика

Комплексная проверка всех аспектов соединения:

```bash
# Без тестов загрузки файлов
telegram-diag full YOUR_BOT_TOKEN

# С config.py (токен и chat_id)
telegram-diag full

# С тестами загрузки файлов
telegram-diag full --chat-id YOUR_CHAT_ID
```

### Использование config.py (рекомендуется)

Создайте файл `config.py` для удобства:

```python
# config.py
BOT_TOKEN = "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
CHAT_ID = 123456789  # опционально, для тестов загрузки файлов
```

Теперь все команды можно использовать без аргументов:

```bash
telegram-diag check     # токен из config.py
telegram-diag monitor   # токен из config.py  
telegram-diag full      # токен и chat_id из config.py
```

**Выполняемые тесты:**

1. **DNS разрешение** - проверка разрешения api.telegram.org
2. **TCP соединение** - проверка соединения на порт 443
3. **Задержка API** - измерение средней задержки (5 попыток)
4. **Пул соединений** - тест 10 параллельных запросов
5. **Загрузка файла** (опционально) - тест отправки 1MB файла

## Интерпретация результатов

### Задержка API

- **< 200ms** - отлично
- **200-500ms** - нормально
- **500-1000ms** - повышенная задержка
- **> 1000ms** - высокая задержка, возможны таймауты

### Рекомендации при проблемах

**Высокая задержка (>1000ms):**

- Увеличьте таймауты в ваших скриптах
- Проверьте качество интернет-соединения
- Рассмотрите использование VPN

**Частые таймауты:**

- Проверьте DNS сервер
- Увеличьте количество повторных попыток
- Добавьте exponential backoff

**Низкая скорость загрузки (<1 Mbps):**

- Увеличьте таймауты для отправки файлов
- Уменьшите размер отправляемых файлов
- Используйте сжатие изображений

## Примеры использования

### Диагностика проблем с отправкой файлов

```bash
# 1. Быстрая проверка соединения
telegram-diag check YOUR_BOT_TOKEN

# 2. Если проблема подтвердилась - полная диагностика
telegram-diag full YOUR_BOT_TOKEN --chat-id YOUR_CHAT_ID
```

### Мониторинг стабильности

```bash
# Запустить мониторинг на 10 минут
telegram-diag monitor YOUR_BOT_TOKEN --interval 5

# Ctrl+C для остановки и просмотра статистики
```

### Автоматизированный мониторинг

```bash
# Linux/Mac - добавить в cron
0 * * * * telegram-diag full YOUR_BOT_TOKEN >> /var/log/telegram-diag.log 2>&1

# Windows - создать задачу в Task Scheduler
```

## Получение chat_id

Для тестов с загрузкой файлов нужен ваш Telegram chat ID:

1. Отправьте любое сообщение боту [@userinfobot](https://t.me/userinfobot)
2. Бот ответит с вашим ID
3. Используйте этот ID в команде `--chat-id`

## Сохранение результатов

Все инструменты автоматически сохраняют результаты в файлы:

- **Мониторинг:** `telegram_monitor_YYYYMMDD_HHMMSS.log`
- **Диагностика:** `telegram_network_diagnostics_YYYYMMDD_HHMMSS.log`
